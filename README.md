# 農業部水產試驗所｜台灣吳郭魚情報站

結合使用者提供的台灣水產教材、官方統計、每日魚市場交易行情、即時氣象、產業消息與 GitHub 開源資源的吳郭魚資訊儀表板。

## 更新方式

- 瀏覽器每 10 分鐘重讀快取資料與 Open-Meteo 氣象。
- GitHub Actions 每 10 分鐘重新抓取消息、公開儲存庫、吳郭魚相關魚市場量價與農業開放資料，成功後部署 GitHub Pages。
- 外部來源失效時保留最後一次成功快照，並在頁面顯示資料狀態。

## 本機執行

```bash
npm ci
npm run update-data
npm run dev
```

## 重要限制

即時氣象是魚塭環境的代理訊號，不等同池內水溫、溶氧、pH 或氨氮感測值。教材數值為操作參考，不替代現場量測、獸醫診斷與主管機關規範。
